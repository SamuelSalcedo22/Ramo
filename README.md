# Ramo para Juli 💐

Un ramo de flores hecho con código: crece en una "terminal" con caracteres de colores, gira solito y al final muestra un mensaje de amor. Si tocas el ramo, salen corazones.

Todo está en un solo archivo: `index.html` (HTML + CSS + JavaScript, sin dependencias).

## Verlo en tu computadora

Descarga `index.html` y ábrelo con doble clic en el navegador.

## Publicarlo con GitHub Pages

1. En este repositorio entra a **Settings → Pages**.
2. En **Build and deployment**, elige **Source: Deploy from a branch**.
3. Elige la rama **main** y la carpeta **/ (root)**, y pulsa **Save**.
4. Espera uno o dos minutos. La página queda en:
   `https://samuelsalcedo22.github.io/Ramo/`

## Cambiar el mensaje

Busca en `index.html` la sección `<section class="letter">` y edita el título y los párrafos.
